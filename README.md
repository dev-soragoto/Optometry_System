# 验光系统 / Optometry System


**🌐 在线访问 / Live Demo:**  https://dev-soragoto.github.io/Optometry_System/


## 中文

### 📋 项目简介

基于Web的验光系统，提供基础的视力检测工具。采用纯前端技术实现，可在浏览器中直接运行。

### ✨ 功能模块

- **物理尺寸校准** - 使用标准信用卡尺寸进行屏幕校准
- **E视力表** - 标准视力表测试
- **红绿精调** - 红绿背景对比测试
- **散光盘** - 放射状线条散光检测
- **蜂窝视标** - 蜂窝状黑点视标
- **交叉视标** - 交叉线条视标

### ⌨️ 快捷键

- `←/→` - 在不同视图间切换
- `↑/↓` - 调整起始视力值
- `Enter` - 触发当前视图的主要操作按钮



## English

### 📋 Overview

A web-based optometry system providing basic vision testing tools. Built with pure frontend technologies and runs directly in browsers.

### ✨ Features

- **Physical Size Calibration** - Screen calibration using standard credit card size
- **E Visual Acuity Chart** - Standard visual acuity testing
- **Duochrome Test** - Red-green background contrast testing
- **Astigmatism Chart** - Radial line astigmatism detection
- **Honeycomb Target** - Honeycomb pattern with black dots
- **Cross Target** - Cross-line target pattern

### ⌨️ Keyboard Shortcuts

- `←/→` - Navigate between views
- `↑/↓` - Adjust starting visual acuity
- `Enter` - Trigger primary action button in current view
